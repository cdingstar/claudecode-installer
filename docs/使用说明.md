# Claude Code 一键安装器（中文版）使用说明

## 这是什么

在 Windows 10/11（64 位）电脑上**双击一下**，自动完成：

- 安装 Node.js 22、Git for Windows、Python 3.12（含 pip 国内镜像源）
- 安装 Claude Code 本体
- 弹出中文配置窗口，选择大模型（GLM / DeepSeek / 通义千问 / 自定义）并填入 API Key
- 配置完成后继续安装 VS Code 编辑器（用户级，含 `code` 命令）
- 全程使用国内镜像（阿里云 / 华为云 / npmmirror），不访问境外下载源
- 不需要管理员权限（无 UAC 弹窗），全部装在当前用户目录

## 使用步骤

1. 把整个安装器文件夹解压到任意位置（如 `D:\ClaudeCode安装器`）
2. 双击 **`双击安装ClaudeCode.bat`**，等待即可（约 5～15 分钟，视网速）
   - 窗口第一行会显示**版本号**（如 `v1.12(20260917)`），反馈问题时请一并告知
3. 安装完成后会自动弹出**模型配置窗口**：
   - 选择供应商（推荐 GLM 或 DeepSeek）
   - 粘贴 API Key（获取方式见窗口灰色提示行，或下表）
   - 点「测试连接」验证 → 「保存并完成」
4. 打开 PowerShell（开始菜单输入 `powershell`），输入 `claude` 回车开始使用

> 还没有 API Key？可以先点「暂时跳过」完成安装，日后双击 **`重新配置APIKEY.bat`** 随时补配。

安装结束后，安装器文件夹里会自动生成一个 **「问题反馈-安装日志-日期.zip」**（内含安装报告 + 全部日志）。

把它发给我们即可：

## 常见问题

### Q0：双击后闪退 / 立即报错（还没开始下载）？
先做包完整性自检：打开 PowerShell，执行：
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "installer\main.ps1" -CheckOnly
```
显示「全部模块加载成功」= 安装包完好，问题在系统/网络层；显示 `[致命 E-SYS-004]` = 安装包文件缺失或被杀毒软件删了，重新解压原 zip 或加白名单。

> 提示：请把安装器文件夹先复制到 `D:\` 或桌面再运行。直接在微信/QQ 的接收目录里运行，文件可能被聊天程序占用导致异常（安装器检测到该场景会给出黄色提醒）。

### Q1：安装到一半断网 / 关掉了窗口，怎么办？
重新双击 `双击安装ClaudeCode.bat`。已装好的组件自动跳过，只补装缺的部分，不会重复安装。

### Q2：出现红色错误框怎么办？
记住框里的**错误 ID**（如 `E-DL-001`），对照下表处理；处理完重新双击安装器：

| 错误 ID | 含义 | 处理建议 |
|---------|------|---------|
| E-SYS-001/002/003 | 系统版本低 / 磁盘不足 / 非 64 位 | 升级 Windows 10+；清理 C 盘 ≥2GB |
| E-NET-001 | 无法连接国内镜像 | 检查网络、代理、防火墙 |
| E-DL-001/002/003 | 下载失败 / 文件损坏 / 不完整 | 一般会自动换镜像重试；持续失败换网络环境 |
| E-AV-001 | 文件被杀毒软件拦截 | 在杀毒软件中把安装器目录和 `C:\Users\用户名\AppData\Local` 加入白名单 |
| E-NODE / E-GIT / E-PY-00x | 对应组件安装失败 | 按错误框建议处理；重跑安装器会自动换方案重试 |
| E-CC-001/002/003 | Claude Code 安装失败 | 重跑安装器（内置 3 套安装方案自动切换） |
| E-CFG-001 | 配置写入失败 | 运行「重新配置APIKEY.bat」单独重配 |

### Q3：怎么验证装好了？
看安装器目录下的 **`安装报告.txt`**（成功清单 + 各组件版本），或日志在 `logs\` 文件夹。

### Q3.5：某个工具装坏了 / 版本混乱，怎么强制重装？
双击 **「修复重装工具.bat」**，输入组件编号（Node.js / Git / Python / Claude Code / VS Code）确认即可——它只卸载本安装器装的用户级副本（不影响系统里其他方式安装的版本），然后自动重新运行安装器补装。

> 安装器的环境检测策略：每个工具安装前先检测环境——**已装且版本达标**（Node ≥18、Claude Code ≥2.0）直接用；不达标才安装；本地 `cache\` 或 `payload\` 已有安装包则不下载直接用。

### Q4：想换模型 / 换 Key？
双击 **`重新配置APIKEY.bat`**，重新选供应商填 Key 即可，立即生效。

### Q4.1：想测试当前配置的模型能不能用？
双击 **`重新配置APIKEY.bat`**，直接点 **「测试已保存配置」**——不用重新填写任何内容，立即实测当前生效的 Key / 接口 / 模型，结果显示在窗口底部。

### Q4.2：想恢复成 Claude Code 官方默认？
双击 **`重新配置APIKEY.bat`**，点 **「恢复官方默认」** 并确认——自动清除第三方供应商配置（原配置会先备份为 `settings.json.bak`），恢复后运行 `claude` 按提示登录官方账号即可。

### Q5：Claude 会说中文吗？
会。安装器已自动写入「始终使用中文回复」的全局指令。（命令行界面本身是英文的，属于正常现象。）

### Q6：装在哪些位置？怎么卸载？
全部在当前用户目录，不动系统：
- Node.js：`C:\Users\用户名\AppData\Local\Programs\nodejs`
- Git：`C:\Users\用户名\AppData\Local\Programs\Git`
- Python：`C:\Users\用户名\AppData\Local\Programs\Python\Python312`
- Claude Code：`C:\Users\用户名\AppData\Roaming\npm`
- 配置：`C:\Users\用户名\.claude\`

卸载：双击 **「卸载ClaudeCode.bat」**，确认后自动删除上述组件并清理环境变量；
个人数据（配置、聊天记录、API Key）默认保留，想彻底清空按提示输入 D 即可。
卸载中可随时按 Ctrl+C 停止；文件被占用时工具会自动重试，仍失败（或提示权限不足）时
按窗口里的提示操作，再重跑一次卸载工具即可接着删完（已删的不会重来）。
（也可手动删除上述文件夹，并在「系统设置 → 环境变量 → 用户变量 Path」中删除对应条目。）

## 无网络环境安装（可选）

默认在线安装。若目标电脑无法上网，向开发者索取「离线版」安装包（`payload\` 已预置全部组件安装文件，约 250MB），解压后正常双击安装即可，全程离线。

> 离线版由开发者在源码目录运行 `make-offline-bundle.sh` 生成，普通用户无需关心。

## 目录结构

```
ClaudeCode安装器/
├── 双击安装ClaudeCode.bat    # 安装入口（双击它）
├── 卸载ClaudeCode.bat        # 一键卸载（个人数据默认保留）
├── 修复重装工具.bat          # 某个组件装坏了，强制卸载重装
├── 重新配置APIKEY.bat        # 随时重配 API Key / 模型
├── 使用说明.md               # 本说明
├── VERSION                   # 版本号（勿删，启动横幅与报告会显示）
├── 安装报告.txt              # 每次安装的结果报告（安装时自动生成）
├── installer\                # 安装逻辑（PowerShell 脚本，勿改）
├── payload\                  # 离线安装包（仅离线版含有）
├── cache\                    # 下载缓存（安装时自动生成，可删）
└── logs\                     # 运行日志（排障时发给技术支持）
```
